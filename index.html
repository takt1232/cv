Project KARST
Django Bootstrap Postgresql

Project Karst Landscape and Subterranean Resource Synthesis Toolkit (KARST). Is our capstone project during our 4th year in college. It is a web application designed to streamline the documentation of cave-related data. Built with Django REST Framework and JavaScript, the system supports nested data entry through dynamic forms and integrates mapping capabilities by converting KML files to GeoJSON for accurate cave visualization. KARST is designed for researchers and field personnel, offering a clean user interface, real-time form validation, and scalable RESTful APIs for efficient data management.
